MATLAB Compiler

1. Prerequisites for Deployment 

. Verify the MATLAB Runtime is installed and ensure you    
  have installed version 9.2 (R2017a).   

. If the MATLAB Runtime is not installed, do the following:
  (1) enter
  
      >>mcrinstaller
      
      at MATLAB prompt. The MCRINSTALLER command displays the 
      location of the MATLAB Runtime installer.

  (2) run the MATLAB Runtime installer.

Or download the Windows 64-bit version of the MATLAB Runtime for R2017a 
from the MathWorks Web site by navigating to

   http://www.mathworks.com/products/compiler/mcr/index.html
   
   
For more information about the MATLAB Runtime and the MATLAB Runtime installer, see 
Package and Distribute in the MATLAB Compiler documentation  
in the MathWorks Documentation Center.    


NOTE: You will need administrator rights to run MCRInstaller.

2026-08-18: Ion Selection GUI hang after mass calibration. Issue: The Ion Selection GUI could appear to hang indefinitely after a mass calibration had been applied. No MATLAB error was generated; the GUI simply failed to finish initializing. Diagnosis: Testing showed that the behavior was independent of the InSpect software version and was tied to the file structure. The specific trigger was the presence of the variable/structure "out.Calibrations". Files without this field opened the Ion Selection GUI normally. Removing the field "Calibrations" from the structure "out" from an affected file also immediately eliminated the hang. Likely mechanism: The Ion Selection GUI passes the complete "out" structure into numerous GUI callbacks/listeners and stores it in GUI UserData, even though the calibration-history structure is not required for ion selection. Retaining the potentially large out.Calibrations structure during GUI construction appears to cause severe performance degradation. Resolution: out.Calibrations should be excluded from the temporary copy of out passed to the Ion Selection GUI while remaining intact in the primary InSpect data structure. The calibration information is therefore preserved but is no longer unnecessarily carried through the ion-selection interface. Impact: This restores normal Ion Selection GUI initialization for datasets containing saved mass-calibration information without altering the calibration itself or the ion-selection workflow.
